# Keerthinath V — Academic & CSE Undergraduate Portfolio

A high-end, single-page personal portfolio website tailored specifically for **Keerthinath V**, Academic Topper and Computer Science & Engineering Undergraduate at **VIT Vellore**.

Designed with an ultra-clean, elegant, and universally appealing aesthetic: a deep midnight violet canvas (`#0a0817`, `#120e2b`), rich purple/indigo glassmorphism cards, glowing neon accents, tactile 3D press-in buttons, and smooth drop-in/fade-in scroll animations.

## 🚀 How to Run & View

### Option 1: Direct File Open (Zero Config)
Simply double-click `index.html` or drag it into any modern web browser (Chrome, Edge, Firefox, Safari). No build tools or package managers required!

### Option 2: Local HTTP Server (Recommended)
Open a terminal in this folder and start a quick local server:

```powershell
# Using Python
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
